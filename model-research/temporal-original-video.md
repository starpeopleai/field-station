The HQ temporal experiment reads verified Field Station archive packages and joins their annotations to the human training snapshot by ID and reviewed crop pixel checksum. Run `temporal_rgb.py --archive PATH --training-root PATH --output PATH --fit-research-head` with PyAV, Pillow, and NumPy installed. The archive and output belong on external storage.

Each sample in the output manifest references a losslessly compressed array of RGB bytes in time, height, width, channel order and a vector of actual time offsets from the reviewed frame. The loader is `training_sequences(output)`. It honors the recorded motion crop and offsets when present. Older packages use the reviewed box and its source presentation timestamp to select nearby frames at approximately ten samples per second. Decoding uses native resolution. A pixel comparison against the full reviewed original verifies the time alignment. The sequence inherits one human label and one original recording group. Splits for future evaluation must keep recording groups together.

The research head summarizes brightness and chromaticity changes inside the reviewed object across the sequence. It is fitted offline and stores its coefficients separately in the dataset directory. A held-out nighttime comparison is necessary before using its scores in live detection.
